# CV-Webseite – Modulararbeit

## 📌 Projektbeschreibung
Im Rahmen dieser Modularbeit habe ich eine responsive CV-Webseite erstellt, welche als ergänzende Referenz für Bewerbungen genutzt werden kann. Ziel war es, eine technisch saubere, übersichtliche und optisch ansprechende Website zu entwickeln.


## 🛠️ Umsetzung
Das Grundgerüst der Webseite habe ich selbstständig mit HTML und CSS aufgebaut. Dabei habe ich grossen Wert auf eine klare Struktur und ein responsives Layout gelegt, sodass die Seite sowohl auf PCs/Laptops als auch auf Mobilgeräten gut dargestellt wird.

Zu Beginn habe ich mich für ein anderes Design entschieden. Während der Entwicklung habe ich dieses jedoch komplett überarbeitet, da ich das ursprüngliche Design als zu unübersichtlich empfand. Das aktuelle Design ist bewusst einfacher gehalten.
Die Detailausarbeitung (Feinschliff im Styling, einzelne Funktionen, Emojis) erfolgte durch die teilweise Unterstützung mit KI (Gemini) sowie mehrheitlich durch fachlichen Austausch mit meinem Ehemann (Informatiker).

## 🔐 Zusatzfunktionen
Ein Login-/Passwortschutz wurde gemäss Vorgabe als zusätzliche Funktion integriert. Die Umsetzung erfolgte in Zusammenarbeit mit meinem Ehemann und dient dazu, bestimmte Inhalte der Webseite zu schützen.

## 🖼️ Bilder
Das Bewerbungsfoto erhielt ich im Rahmen des Fotoshootings für die hftm. Das Bild ist demnach ein professionelles, durch einen Fotografen mit entsprechender Ausrüstung aufgenonommen worden. Dennoch ist es auf der Webseite zunächst unscharf dargestellt wurde, weswegen ich die Bildschärfe mit Unterstützung von Gemini optimiert habe, sodass die Qualität korrekt wiedergegeben wird.

## 🚀 Technologien
- HTML5 (semantische Struktur)
- CSS3 (Layout, Responsive Design)
- JavaScript (Interaktivität, Login-Funktion)
